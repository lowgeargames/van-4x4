Low Gear Games

Van 4x4

Game Design Document

Visão Geral

Van 4x4 é um jogo 3D de direção off-road com física arcade e visual low-poly. O jogador controla uma van praticamente indestrutível e precisa atravessar terrenos difíceis para chegar até diferentes locais e realizar serviços de manutenção.

O foco principal do jogo está na dirigibilidade exagerada, exploração dos ambientes e nas situações inesperadas geradas pela física.

Equipe

Luciano Ludwig Heling

Desenvolvimento individual do projeto.

Funções: Game Design, Programação, Level Design, Arte 3D, Testes e Gerenciamento do Projeto.

Gameplay

O ciclo principal do jogo será:

Receber missão → Dirigir até o local → Superar o terreno → Realizar o reparo → Receber recompensa → Melhorar a van

Tecnologias

O jogo será desenvolvido utilizando Godot 4 e GDScript. O Visual Studio Code será utilizado para programação, Git e GitHub para versionamento e gerenciamento do projeto e Blender para criação e edição de modelos 3D.
