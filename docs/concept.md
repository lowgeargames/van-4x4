# Van 4x4 — Game Concept

## Ideia geral

Van 4x4 é um jogo 3D de direção off-road com física arcade e visual low-poly.

O jogador controla uma van praticamente indestrutível e deve atravessar terrenos difíceis para chegar até diferentes locais e realizar pequenos serviços de manutenção, como reparar torres, antenas, estações e outros equipamentos.

A principal proposta do jogo é tornar a própria direção divertida. A van poderá atravessar lama, rios, terrenos inclinados, saltar, derrapar e capotar, utilizando uma física propositalmente exagerada em vez de buscar uma simulação realista.

## Gameplay

O ciclo principal será:

**Receber missão → dirigir até o local → superar o terreno → realizar o reparo → receber recompensa → melhorar a van.**

Conforme o jogo avança, novos terrenos, obstáculos e condições climáticas poderão aumentar a dificuldade, incluindo chuva, tempestades, raios e outros eventos ambientais.

O jogador poderá utilizar as recompensas das missões para obter melhorias para a van ou novas ferramentas.

## Objetivo do projeto

O objetivo é criar um jogo simples, leve e rápido de aprender, com foco principalmente em mecânica, física e diversão.

O visual será 3D low-poly para manter o jogo leve e permitir que rode bem em diferentes computadores.

O desenvolvimento será realizado individualmente durante a disciplina de Jogos Digitais utilizando Godot.
