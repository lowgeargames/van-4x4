# Pré-escuta de efeitos curtos

Pasta reservada para as gravações escolhidas dos próximos efeitos. **Está vazia de
propósito:** nenhum efeito foi criado ou sintetizado, e nenhuma gravação foi
escolhida ainda.

Crie estas subpastas quando houver gravações (WAV, OGG ou MP3):

| Pasta | Efeito |
|---|---|
| `arvore/` | árvore quebrando |
| `madeira_folhas/` | madeira e folhas |
| `caixas/` | impacto em caixas |
| `barris/` | impacto em barris |
| `aterrissagem/` | aterrissagem |
| `agua/` | água |

No laboratório (`demo/engine_audio_demo.tscn`, F6): F3 → aba **EFEITOS** → os
arquivos de cada pasta aparecem como botões; **REESCANEAR** relê as pastas sem
reiniciar a cena. A pré-escuta toca no volume geral do laboratório.

Antes de usar qualquer gravação no jogo, registre autor, título, link, licença e
modificações em `../../CREDITS.md`. Não coloque aqui efeitos sintéticos nem
substitutos de baixa qualidade. Ligar os sons a eventos do jogo é outra etapa.
